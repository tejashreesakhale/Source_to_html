# 🚀 Source to HTML Converter

## 📌 About the Project

Source to HTML Converter is a C programming project that converts C source code into an HTML file with syntax highlighting.

It reads the source code from a text file, identifies different elements of C programming, and generates an HTML output file. This makes source code easier to read and understand in a web browser.

## ✨ Features

- Reads C source code from a file.
- Identifies C keywords and other programming elements.
- Handles header files and string literals.
- Converts special HTML characters into HTML entities.
- Generates a structured HTML document.
- Displays source code with improved readability.

## 🛠️ Technologies Used

- C Programming
- File Handling
- String Handling
- HTML
- GCC Compiler

## 📂 Project Structure

```text
Source_to_html/
│
├── main.c
├── source.c
├── source.h
├── sample.txt
├── output.html
└── README.md
```

## ⚙️ How to Compile

Compile the project using GCC:

```bash
gcc main.c source.c -o source_to_html
```

## ▶️ How to Run

Execute the compiled program:

```bash
./source_to_html
```

The program reads the input from `sample.txt` and generates the converted HTML file named `output.html`.

## 📄 Input and Output

**Input:** `sample.txt`

Contains the C source code that needs to be converted.

**Output:** `output.html`

Contains the generated HTML representation of the source code.

Open `output.html` in any web browser to view the result.
